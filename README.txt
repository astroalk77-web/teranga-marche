TERANGA MARCHE - VERSION FRONTEND

FICHIERS
- index.html : accueil et choix du profil acheteur/producteur.
- acheteur.html : catalogue, recherche, filtres et contact WhatsApp.
- producteur.html : publication et suppression des annonces.
- style.css : styles des interfaces.
- script.js : logique JavaScript et stockage local.

OUVRIR LE PROJET
1. Ouvrez le dossier Teranga_Marche dans VS Code.
2. Lancez index.html avec l'extension Live Server.
3. Choisissez Acheteur ou Producteur.

LIMITES DE CETTE VERSION
Cette version est uniquement frontend. Les annonces sont conservées dans le localStorage du navigateur.
Elles ne sont pas envoyées à un serveur et ne sont pas partagées entre appareils ou utilisateurs.
Le backend, les comptes, l'authentification et la base de données seront ajoutés ultérieurement.
